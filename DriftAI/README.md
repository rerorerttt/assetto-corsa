# DriftAI v1.2.0

Автономный дрифт для всех AI-машин в Assetto Corsa. CSP Lua App для **Custom Shaders Patch 0.3.2-preview2** (build 4305) и новее.

После запуска обычной офлайн-сессии приложение **сразу фиксирует границы трассы**, затем автоматически находит все машины под управлением AI, отключает штатный AI-контроллер и ведёт каждую машину в управляемом заносе: газ держит пробуксовку задних колёс, скорость планирует по расстоянию до стен.

## Что нового в v1.2.0

- **Границы фиксируются автоматически при старте сессии** — ещё до нажатия кнопки: как только сессия ожила, приложение за несколько кадров сканирует всю трассу (`physics.raycastTrack`, шаг 8 м) — вертикальные лучи подтверждают проезжаемую поверхность, горизонтальные измеряют стены слева/справа/впереди.
- **Газ всегда стремится к пробуксовке**: цель — фактический slip ratio задних колёс 0.30. Если буксы не хватает, газ интегрируется вверх сам; если и на полном газу буксы нет дольше 0.45 с — автоматически запрашивается пониженная передача (`requestedGearIndex`).
- **Детерминированный вход в дрифт**: на 55+ км/ч контроллер бьёт ручником 0.4 с на полном газу — занос развивается на любом участке трассы, а не только там, где случайно есть поворот.
- **Без телеметрии колёс машина больше не ползёт**: по умолчанию почти полный газ (0.95), регулируемый углом скольжения кузова.
- **Не врезается**: лимит скорости всегда вписывает тормозной путь до ближайшей стены в свободную дорогу — `sqrt(2·a·(d − 8 м))`; при ≥120 м свободно — длинный быстрый дрифт (газ ≥ 0.9), предел 150 км/ч.

## Установка

1. Установите CSP 0.3.2-preview2 или новее (build ≥ 4305).
2. Скопируйте папку `DriftAI` в `assettocorsa/apps/lua/DriftAI`.
3. Включите приложение DriftAI в Content Manager.

## Использование

1. Запустите офлайн-сессию и добавьте AI-соперников.
2. Границы трассы зафиксируются сами в первые секунды сессии.
3. Откройте DriftAI на панели приложений, нажмите «Запустить дрифт».
4. Все AI-машины начнут дрифтить. «Остановить» — вернуть штатный AI.

## Файлы

| Файл | Назначение |
|---|---|
| `manifest.ini` | Регистрация приложения в CSP |
| `DriftAI.lua` | Жизненный цикл, авто-карта границ при старте сессии, сканер AI, UI |
| `driver.lua` | Контроллер дрифта: пробуксовка, авто-понижение передачи, скорость по стенам |
| `bounds.lua` | Карта границ трассы (вертикальные коллизии + стены) |
| `track.lua` | Навигация по геометрии трассы без fastline |

## Перехват управления (CSP 0.3.2-preview2)

- `ac.overrideCarControls(i)` → `ac.CarControlsInput` — работает для AI-машин из Lua-приложений.
- `combineAxis = false` — полная замена газа/тормоза/ручника вместо суммирования; `steer` заменяет всегда; `requestedGearIndex` — прямая передача.
- `CarControlsInput:active()` — приложение каждую секунду проверяет, что физика потребляет команды.
- Штатный AI нейтрализуется `physics.setAIAggression/setAICaution/setAILevel`, отъезд в боксы запрещён `physics.preventAIFromRetiring`.

## Ограничения

- Только офлайн-сессии (в онлайн CSP не даёт приложениям управлять чужими машинами).
- `physics.*` требует `[_SCRIPTING_PHYSICS] ALLOW_TOOLS=1` в `surfaces.ini` трассы (обычно включено).
- Тюнинговые константы (цель пробуксовки 0.30, скорость входа 55 км/ч, предел 150 км/ч, запас до стены 8 м) — в начале `driver.lua`.
