# DriftAI v1.2.1

Автономный дрифт для всех AI-машин в Assetto Corsa. CSP Lua App для **Custom Shaders Patch 0.3.2-preview2** (build 4305) и новее.

После загрузки сессии приложение **сразу фиксирует границы трассы** лучами, затем автоматически находит все машины под управлением AI, отключает штатный AI-контроллер и ведёт каждую машину в управляемом заносе: газ всегда стремится к пробуксовке задних колёс, скорость планирует по свободному коридору до ближайшей теснины.

## Что нового в v1.2.1

- **Границы фиксируются автоматически при старте сессии** — ещё до нажатия кнопки: вертикальные лучи (`physics.raycastTrack`) подтверждают проезжаемую поверхность, горизонтальные измеряют стены слева/справа/впереди, шаг 8 м, за несколько кадров без фриза.
- **Детерминированный вход в занос (`initiate`)**: на 70+ км/ч — резкий поворот руля (0.9), полный газ и пульсирующий ручник (0.35 с каждые 0.8 с) до появления угла скольжения 12°. Если сцепление не сорвано за 2.5 с — повтор в другую сторону. Дрифт начинается **на любом участке**, включая прямые.
- **Газ под пробуксовку (wheelspin-first)**: полный газ по умолчанию; подрезается только при перевыше цели (slip ratio задних колёс 0.35). Полный газ без букса дольше 0.35 с — немедленный запрос пониженной передачи (`requestedGearIndex`, кулдаун 3 с против раскачки). Без телеметрии колёс — просто полный газ.
- **Скорость по свободному коридору**: лимит считается по длине свободного коридора впереди (`bounds.lua:freeCorridor`), а не по худшему лучу — быстрые связки больше не душатся далёким барьером. `v = sqrt(2·8·(коридор − 12 м))`, предел 170 км/ч. Коридор ≥150 м и занос установлен — длинный быстрый дрифт (газ ≥0.95).
- **Узкие места**: суммарный зазор слева+справа <10 м — лимит 90 км/ч.

## Установка

1. Установите CSP 0.3.2-preview2 или новее (build ≥ 4305).
2. Скопируйте папку `DriftAI` в `assettocorsa/apps/lua/DriftAI`.
3. Включите приложение DriftAI в Content Manager.

## Использование

1. Запустите офлайн-сессию и добавьте AI-соперников.
2. Границы трассы зафиксируются сами в первые секунды сессии.
3. Откройте DriftAI на панели приложений, нажмите «Запустить дрифт».
4. Все AI-машины начнут дрифтить. «Остановить» — вернуть штатный AI.

## Файлы

| Файл | Назначение |
|---|---|
| `manifest.ini` | Регистрация приложения в CSP |
| `DriftAI.lua` | Жизненный цикл, авто-карта границ при старте сессии, сканер AI, UI |
| `driver.lua` | Контроллер дрифта: initiate-вход, пробуксовка, авто-понижение передачи, скорость по коридору |
| `bounds.lua` | Карта границ трассы: вертикальные коллизии + стены + `freeCorridor` |
| `track.lua` | Навигация по геометрии трассы без fastline |

## Перехват управления (CSP 0.3.2-preview2)

- `ac.overrideCarControls(i)` → `ac.CarControlsInput` — работает для AI-машин из Lua-приложений.
- `combineAxis = false` — полная замена газа/тормоза/ручника вместо суммирования; `steer` заменяет всегда; `requestedGearIndex` — прямая передача.
- `CarControlsInput:active()` — приложение каждую секунду проверяет, что физика потребляет команды.
- Штатный AI нейтрализуется `physics.setAIAggression/setAICaution/setAILevel`, отъезд в боксы запрещён `physics.preventAIFromRetiring`.

## Ограничения

- Только офлайн-сессии (в онлайн CSP не даёт приложениям управлять чужими машинами).
- `physics.*` требует `[_SCRIPTING_PHYSICS] ALLOW_TOOLS=1` в `surfaces.ini` трассы (обычно включено).
- Тюнинговые константы (цель пробуксовки 0.35, вход 70 км/ч, предел 170 км/ч, запас до теснины 12 м) — в начале `driver.lua`.
