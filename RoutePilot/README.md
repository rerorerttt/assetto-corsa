# RoutePilot 0.5

CSP Lua app for Assetto Corsa. Records a custom route from the player car and controls AI cars on that route, including centralized passing, crossing traffic coordination, recovery and a cached static-collision scan.

## Install

Copy the `RoutePilot` folder into:

`assettocorsa/apps/lua/RoutePilot/`

Enable RoutePilot in Content Manager's Lua Apps list. Keep `manifest.ini`, `RoutePilot.lua` and `logger.lua` together.

## First use

Record a route by driving it, stop recording, keep loop mode enabled for a circuit, and save the route for the current track/layout. RoutePilot loads the matching route on startup. The app controls steering, throttle and brake; the car retains control of its gearbox/transmission.

## Current controller

- Arcade speed profile: 240 km/h default setting, adjustable from 100 to 320 km/h, with deterministic per-car pace variation.
- Higher corner-speed floor and stronger throttle retention during high-slip drifting.
- Centralized same-direction pass/yield reservations, head-on right-side meetings, and deterministic right-of-way for crossing AI paths.
- Reserved AI pairs are exempted from normal mutual following and most predictive braking while carrying out their agreed manoeuvre.
- Incremental static track scan via CSP `physics.raycastTrack()`. It samples eight horizontal directions at three heights along the route, then stores the nearest physics-surface hits in versioned comment records appended to the route file. A rescan action is available in the UI.
- Stuck, airborne and off-route recovery; periodic telemetry in `routepilot_trace.txt`.

## Collision map file behaviour

The collision map is generated by the app while Assetto Corsa is running. It is saved into the local per-track route file as `#RP_OBSTACLE_V1` and `#RP_OBS` comment rows; the XYZ route parser ignores these rows, preserving compatibility. The GitHub copy of `line_nevadadrift.txt` will not acquire real collision hits until the app has run the scan locally and that resulting file is uploaded or committed.

The scanner only detects physics surfaces. Visible KN5 objects without collision geometry are not guaranteed to be detected.

## Validation status

The current branch contains a substantial first arcade-traffic revision, but it has not yet been validated in Assetto Corsa. The previous supplied trace averaged about 56 km/h across five AI cars despite an average target speed near 103 km/h; it showed assigned pass/yield roles but emergency braking interrupted manoeuvres. The new code targets those causes, but only a fresh in-game trace can establish whether the cars now maintain speed and complete overtakes.

Read `DEVELOPMENT.md` before changing the coordinator or obstacle cache. It contains the current implementation, SDK references, telemetry findings and required test cases.
